### 1. Chart `/trade` mati total (canvas 0, status "LOADING…")

**Gejala:** halaman ke-render tapi chart kosong, badge loading terus, dan **nol** request
ke `/api/prices` maupun GeckoTerminal — padahal `curl /api/prices` balikin 200 + 135 token.

**Akar:** Next.js 16 memblokir request cross-origin ke dev resource (`/_next/hmr`).
Websocket HMR gagal → hydration klien mati → semua `useEffect` (chart, poll harga, swaps)
tidak pernah jalan.

**Fix** — `next.config.ts`:
```ts
allowedDevOrigins: [
  "127.0.0.1",
  "localhost",
  "conventions-beneficial-bringing-garlic.trycloudflare.com",
  "*.trycloudflare.com",
],
```
Plus `rm -rf .next` + restart bersih (build Turbopack sebelumnya keinterupsi).

**Bukti:** canvas 7, badge `GECKOTERMINAL`, request 200 ke `geckoterminal/ohlcv` +
`/api/prices`, nol page error.

### 4. Search token di top bar (sebelumnya `Coming soon`, disabled)

**Baru:**

| File | Isi |
|---|---|
| `src/app/api/search/route.ts` | Route search |
| `src/components/app/token-search.tsx` | Komponen dropdown (klien) |

**Diubah:** `src/components/app/app-shell.tsx` — span "Coming soon" → `<TokenSearch />`

**Sumber data:**
```
ketik nama/symbol
  ├─ katalog lokal ARC_EVERY (124 token)      → instan
  ├─ DexScreener /latest/dex/search?q=        → token di luar katalog
  └─ Peach POST /arc/v1/arc/pro/v2/coins      → harga/vol/liq/mcap live
     dedupe: per pairAddress, lalu per symbol/quote (ambil liquidity terdalam)
     rank: symbol exact → starts-with → name → substring → volume desc

paste address (0x + 40 hex, atau pair address 64 hex)
  ├─ katalog lokal dulu
  └─ DexScreener /latest/dex/tokens/<addr> filter chainId=arc
```

Debounce 250ms (address 0ms — itu lookup), min 2 karakter, limit 12.
`⌘K`/`Ctrl+K` fokus · `↑↓` navigasi · `Enter` buka · `Esc` tutup · klik luar nutup.

**Tiga bug yang ketemu & dibereskan saat bikin ini:**

1. **Panel nutupin kolom search.** Panel di-portal ke `<body>` biar lepas dari stacking
   context + kotak 64px header. Koordinat **viewport-space** (`r.bottom + 8`, tanpa
   scroll offset) karena input-nya di header `position: fixed`. Di-refresh pakai rAF loop.
2. **`position: fixed` kalah sama `.home-glass`.** `globals.css` baris 179 punya
   `.home-glass { position: relative }` → panel jadi *relative*, dan karena di akhir
   `<body>` posisinya nongkrong di y≈3894. Fix: `position` dipindah ke **inline style**
   (inline menang atas stylesheet).
3. **Klik pake kursor nggak jalan, cuma Enter.** Handler outside-click cek
   `boxRef.contains(target)`, tapi panel udah bukan anak `boxRef`. Jadi `mousedown` di
   baris hasil dianggap klik-luar → `setOpen(false)` → `onClick` baris nggak pernah
   kepanggil. Fix: tambah `panelRef` dan cek dua-duanya.
